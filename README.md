# Uttarakhand landslide priority map

This repository holds only the built files of the website at https://tanmay-22.github.io/uttarakhand-landslide-map/.
They are generated by a research model of rainfall-triggered landslides in Uttarakhand, India,
and pushed here by `python -m landslide.publish`. Do not edit them by hand.

This is a research model, not an official warning. For official warnings see the Uttarakhand
State Disaster Management Authority (https://usdma.uk.gov.in/) and the India Meteorological
Department (https://mausam.imd.gov.in/).
